सुरक्षा निर्देश / SAFETY INSTRUCTIONS

यात्रा से पहले / BEFORE JOURNEY
  • वाहन जांच / Vehicle Inspection: ब्रेक, टायर, लाइट्स की पूरी जांच करें / Check brakes, tires, lights completely
  • टैंक सत्यापन / Tank Verification: टैंक और वाल्व की जांच करें / Inspect tank and valves
  • दस्तावेज / Documents: ADR प्लेकार्ड और परमिट सत्यापित करें / Verify ADR placard and permits
  • आपातकालीन उपकरण / Emergency Equipment: अग्निशामक यंत्र और स्पिल किट जांचें / Check fire extinguisher and spill kit
  • संपर्क नंबर / Contact Numbers: सभी आपातकालीन नंबर सेव करें / Save all emergency numbers
यात्रा के दौरान / DURING JOURNEY
  • गति सीमा / Speed Limit: अधिकतम {{ tt_specs.max_speed if tt_specs and tt_specs.max_speed else '50' }} किमी/घंटा / Maximum {{ tt_specs.max_speed if tt_specs and tt_specs.max_speed else '50' }} km/h
  • मोड़ों पर / At Turns: गति 10-15 किमी/घंटा तक कम करें / Reduce speed to 10-15 km/h
  • दूरी / Following Distance: 6 सेकंड का अनुसरण दूरी बनाए रखें / Maintain 6 seconds following distance
  • विश्राम / Rest Breaks: हर 2 घंटे में 15 मिनट का विश्राम लें / Take 15 minutes rest every 2 hours
  • तरल निगरानी / Liquid Monitoring: तरल पदार्थ के उछाल पर ध्यान दें / Monitor liquid surge
  • मौसम / Weather: खराब मौसम में अतिरिक्त सावधानी बरतें / Exercise extra caution in bad weather
आपातकालीन प्रक्रिया / EMERGENCY PROCEDURES
  • रिसाव / Spill: क्षेत्र को अलग करें, तुरंत 101 पर कॉल करें / Isolate area, call 101 immediately
  • आग / Fire: 300 मीटर निकासी त्रिज्या, केवल फोम दमन, 101 डायल करें / 300m evacuation radius, foam suppression only, dial 101
  • पलटना / Rollover: इंजन बंद करें, सुरक्षित दूरी बनाए रखें / Shut engine, maintain safe distance
  • दुर्घटना / Accident: 108 (एम्बुलेंस), 100 (पुलिस) कॉल करें / Call 108 (Ambulance), 100 (Police)
  • यांत्रिक खराबी / Breakdown: सुरक्षित स्थान पर रुकें, चेतावनी त्रिकोण लगाएं / Stop at safe place, place warning triangle
